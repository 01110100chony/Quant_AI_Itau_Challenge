# Relatórios e artefatos

Esta pasta receberá tabelas, figuras e entregáveis produzidos por código reproduzível. Arquivos gerados devem indicar o experimento e a configuração de origem.

As subpastas `figures/` e `tables/` são ignoradas por padrão para evitar versionamento acidental de saídas transitórias; remova a regra do `.gitignore` apenas quando um artefato for deliberadamente congelado.
