# Código reutilizável

Funções estabilizadas nos notebooks devem migrar para esta pasta quando houver reutilização real. Prioridades prováveis para o próximo feasibility:

- carregamento e validação de snapshots;
- calendários, sessões e conversão para UTC;
- alinhamento point-in-time;
- métricas e validações sem look-ahead.

Não criar módulos antes de a specification correspondente ser aprovada.
